# Number Plates

Interactive demo of Russian vehicle plate formats with lookup tables for regions, diplomatic codes, and military codes.

## Features
- Civilian, diplomatic, and military plate layouts
- Search by region/country/military unit and auto-fill plate codes
- Reference tables with tabs and modal overlay

## Getting Started

### Install

```bash
npm install
```

### Run (dev)

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Project Structure
- src/main.ts: UI rendering and state handling
- src/style.css: styling
- src/data/*.ts: lookup data
- public/fonts: local fonts (Golos Text)

## Notes
- The UI uses the locally hosted Golos Text font (see public/fonts).
